The `List<E>` interface represents an ordered sequence of elements where duplicates and `null` values are allowed. Elements can be inserted or accessed by their integer index.

---

## List Implementations Comparison

<Mermaid
  chart={`
flowchart TD
    LIST["List&lt;E&gt; (Ordered, Index-Based)"]
    LIST --> AL["ArrayList (Dynamic Resizing Array)"]
    LIST --> LL["LinkedList (Doubly-Linked Nodes)"]
    LIST --> VEC["Vector (Synchronized Array)"]
    VEC --> STACK["Stack (LIFO, Extends Vector)"]
`}
/>

| Class            | Internal Structure           | Access (`get(i)`) |  Append (`add`)  | Head Insert/Delete |  Thread Safe  |
| :--------------- | :--------------------------- | :---------------: | :--------------: | :----------------: | :-----------: |
| **`ArrayList`**  | Contiguous dynamic array     |      `O(1)`       | `O(1)` amortized |       `O(n)`       |      No       |
| **`LinkedList`** | Doubly-linked discrete nodes |      `O(n)`       |      `O(1)`      |       `O(1)`       |      No       |
| **`Vector`**     | Synchronized dynamic array   |      `O(1)`       | `O(1)` amortized |       `O(n)`       | Yes (Locking) |
| **`Stack`**      | Extends `Vector` (LIFO)      |      `O(1)`       |      `O(1)`      |    `O(1)` (top)    | Yes (Locking) |
