A one-dimensional (1D) array is a fixed-size, zero-indexed sequence of elements allocated contiguously in memory. Unlike dynamic collections, 1D arrays are low-level Java language constructs that can store primitive types with zero boxing overhead or object reference pointers.

---

## Declaration & Instantiation

Java provides three primary syntax forms for creating 1D arrays:

```java title="ArrayCreation.java"
// 1. Declaration + Allocation with default zero values (Heap allocated)
int[] nums = new int[5]; // length = 5, all elements = 0

// 2. Array Literal (compiler allocates and initializes values immediately)
int[] primes = {2, 3, 5, 7, 11}; // length = 5

// 3. Explicit Anonymous Array (useful when passing inline to methods or returning)
int[] scores = new int[]{98, 85, 92};
printScores(new int[]{100, 95, 90}); // pass inline without declaring a variable
```

<Callout type="warn">
  **Java Style vs C-Style Declaration**: Always place brackets next to the data type (`int[] arr`)
  rather than the variable name (`int arr[]`). Placing brackets on the type avoids subtle
  multi-variable declaration bugs: ```java int[] a, b; // Both a and b are int[] (Java style -
  Recommended) int a[], b; // a is int[], but b is a plain primitive int! (C-style trap) ```
</Callout>

### Default Initialization Values

When an array is allocated using the `new` keyword, the JVM automatically initializes all memory slots to type-specific default values:

| Element Type                                       |     Default Value      | Code Example                                                   |
| :------------------------------------------------- | :--------------------: | :------------------------------------------------------------- |
| `byte`, `short`, `int`, `long`                     |          `0`           | `int[] arr = new int[3]; // [0, 0, 0]`                         |
| `float`, `double`                                  |         `0.0`          | `double[] arr = new double[2]; // [0.0, 0.0]`                  |
| `boolean`                                          |        `false`         | `boolean[] visited = new boolean[3]; // [false, false, false]` |
| `char`                                             | `'\u0000'` (null char) | Prints as empty whitespace or NUL                              |
| Any Object Reference (`String`, `Integer`, `Node`) |         `null`         | `String[] words = new String[2]; // [null, null]`              |

### Array Length: Field, Not a Method

In Java, arrays expose length as a `public final` **field** (`arr.length`), **not a method** (`arr.length()` will trigger a compile error):

```java title="ArrayLength.java"
int[] nums = {10, 20, 30, 40};

int len = nums.length; // Correct: direct field access
// int bad = nums.length(); // COMPILE ERROR: cannot find symbol method length()
```

<Callout type="info">
  **Why is `length` a field on arrays, but a method on Strings and Lists?** - **`arr.length`
  (Field)**: The JVM allocates arrays with a fixed memory buffer. The length is stored directly as a
  32-bit integer in the array's 16-byte object header and accessed via the direct CPU/bytecode
  instruction `arraylength` with zero method-call overhead. - **`str.length()` (Method)**: `String`
  encapsulates an internal byte array (`byte[] value`) and requires an accessor method to respect
  OOP encapsulation. - **`list.size()` (Method)**: `List` and collections have dynamic capacities
  that mutate over time.
</Callout>

## Printing 1D Arrays in Java

A classic beginner and interview trap is attempting to print an array directly using `System.out.println(arr)`:

```java title="ArrayPrintingTrap.java"
int[] nums = {1, 2, 3};
System.out.println(nums); // Prints: [I@6828a2a8 (NOT [1, 2, 3]!)
```

<Callout type="info">
  **Why does this happen?** Arrays do not override `Object.toString()`. Java inherits the default
  implementation: `getClass().getName() + "@" + Integer.toHexString(hashCode())`. For `int[]`, `[I`
  signifies a 1D integer array followed by its hexadecimal memory identity hashcode.
</Callout>

### Comprehensive Printing Methods

<Tabs items={["Arrays.toString()", "Classic for-loop", "Enhanced for-each", "Streams", "String.join()"]}>
  <Tab value="Arrays.toString()">
    The standard and most idiomatic one-liner for 1D arrays:

    ```java title="PrintArraysToString.java"
    import java.util.Arrays;

    int[] nums = {10, 20, 30, 40};
    System.out.println(Arrays.toString(nums));
    // Output: [10, 20, 30, 40]

    String[] words = {"Java", "DSA", "Guide"};
    System.out.println(Arrays.toString(words));
    // Output: [Java, DSA, Guide]
    ```

  </Tab>

  <Tab value="Classic for-loop">
    Use when custom delimiters, index-based formatting, or boundary markers are needed:

    ```java title="PrintForLoop.java"
    int[] nums = {10, 20, 30, 40};

    System.out.print("[");
    for (int i = 0; i < nums.length; i++) {
        System.out.print(nums[i]);
        if (i < nums.length - 1) {
            System.out.print(", ");
        }
    }
    System.out.println("]");
    // Output: [10, 20, 30, 40]
    ```

  </Tab>

  <Tab value="Enhanced for-each">
    Clean, readable iteration when element indices are not required:

    ```java title="PrintForEach.java"
    int[] nums = {10, 20, 30, 40};

    for (int n : nums) {
        System.out.print(n + " ");
    }
    System.out.println();
    // Output: 10 20 30 40
    ```

  </Tab>

  <Tab value="Streams">
    Leverage Java 8+ functional streams for complex formatting or downstream pipelines:

    ```java title="PrintStreams.java"
    import java.util.Arrays;
    import java.util.stream.Collectors;

    int[] nums = {10, 20, 30, 40};

    // 1. Direct stream printing
    Arrays.stream(nums).forEach(n -> System.out.print(n + " "));
    System.out.println();

    // 2. Joining into a custom bracketed string
    String formatted = Arrays.stream(nums)
        .mapToObj(String::valueOf)
        .collect(Collectors.joining(" -> ", "<", ">"));
    System.out.println(formatted);
    // Output: <10 -> 20 -> 30 -> 40>
    ```

  </Tab>

  <Tab value="String.join()">
    Best for arrays of `String` or `CharSequence`:

    ```java title="PrintStringJoin.java"
    String[] tags = {"Algorithms", "DataStructures", "Performance"};

    String result = String.join(" | ", tags);
    System.out.println(result);
    // Output: Algorithms | DataStructures | Performance
    ```

  </Tab>
</Tabs>

## Cloning & Copying 1D Arrays

<Tabs items={["Arrays.copyOf()", "clone()", "System.arraycopy()"]}>
  <Tab value="Arrays.copyOf()">
    High-level and concise; pads with zeros or truncates if `newLength != orig.length`:

    ```java title="CopyOfExample.java"
    int[] orig = {10, 20, 30};

    // Exact copy
    int[] copy = Arrays.copyOf(orig, orig.length); // [10, 20, 30]

    // Padded copy
    int[] padded = Arrays.copyOf(orig, 5); // [10, 20, 30, 0, 0]

    // Slice copy [from, to)
    int[] slice = Arrays.copyOfRange(orig, 1, 3); // [20, 30]
    ```

  </Tab>

  <Tab value="clone()">
    For 1D primitive arrays, `.clone()` produces a safe, independent copy:

    ```java title="CloneExample.java"
    int[] orig = {1, 2, 3};
    int[] copy = orig.clone();

    copy[0] = 999;
    System.out.println(orig[0]); // 1 (original unaffected)
    ```

    <Callout type="warn">
      For **object arrays** (`String[]`, `User[]`), `.clone()` performs a **shallow copy**—the references inside the array still point to the original objects!
    </Callout>

  </Tab>

  <Tab value="System.arraycopy()">
    Hardware-accelerated native JVM memory copy (`memmove`). The fastest method for copying slices between arrays:

    ```java title="SystemArrayCopyDemo.java"
    int[] src = {1, 2, 3, 4, 5};
    int[] dest = new int[5];

    // System.arraycopy(src, srcPos, dest, destPos, length)
    System.arraycopy(src, 1, dest, 0, 3);
    // dest becomes: [2, 3, 4, 0, 0]
    ```

  </Tab>
</Tabs>

## Complexity Profile

| Operation                          | Time Complexity | Space Complexity | Notes / Invariants                                    |
| :--------------------------------- | :-------------: | :--------------: | :---------------------------------------------------- |
| **Index Access** (`arr[i]`)        |     `O(1)`      |      `O(1)`      | Direct offset calculation: `base + (i * elementSize)` |
| **Search (Unsorted)**              |     `O(n)`      |      `O(1)`      | Linear scan                                           |
| **Search (Sorted)**                |   `O(log n)`    |      `O(1)`      | Binary search (`Arrays.binarySearch`)                 |
| **Insert / Delete at Index**       |     `O(n)`      |      `O(1)`      | Requires shifting elements via `System.arraycopy`     |
| **Dual-Pivot Quicksort** (`int[]`) |  `O(n log n)`   |    `O(log n)`    | Unstable primitive sorting in `Arrays.sort`           |
| **TimSort** (`Object[]`)           |  `O(n log n)`   |      `O(n)`      | Stable, adaptive sorting in `Arrays.sort`             |

## java.util.Arrays Toolkit

The primary static toolkit provided by the JDK for 1D arrays:

| Method / Property                   | Parameters               |       Return Type       | Description / Notes                                                                                 |
| :---------------------------------- | :----------------------- | :---------------------: | :-------------------------------------------------------------------------------------------------- |
| `arr.length`                        | _(property)_             |          `int`          | **Public final field** (NOT a method). Stored in JVM object header; read via `arraylength` bytecode |
| `Arrays.sort(arr)`                  | `(int[]\|double[]\|...)` |         `void`          | Sorts primitives via Dual-Pivot Quicksort (`O(n log n)`)                                            |
| `Arrays.sort(T[] a, Comparator c)`  | `(T[] a, Comparator c)`  |         `void`          | Sorts objects via TimSort (`O(n log n)`, stable)                                                    |
| `Arrays.parallelSort(arr)`          | `(int[]\|double[]\|...)` |         `void`          | Multi-core ForkJoinPool sort for arrays `> 8192` items                                              |
| `Arrays.binarySearch(arr, key)`     | `(arr, key)`             |          `int`          | Precondition: array **must be sorted**. Returns index or `-(insertion_point) - 1`                   |
| `Arrays.fill(arr, val)`             | `(arr, val)`             |         `void`          | Assigns `val` to every slot                                                                         |
| `Arrays.equals(a, b)`               | `(a, b)`                 |        `boolean`        | Element-by-element equality check                                                                   |
| `Arrays.mismatch(a, b)`             | `(a, b)`                 |          `int`          | Returns index of first differing element, or `-1` if identical (Java 9+)                            |
| `Arrays.stream(arr)`                | `(arr)`                  | `IntStream / Stream<T>` | Produces primitive or object stream                                                                 |
| `Arrays.copyOf(arr, newLen)`        | `(arr, int)`             |          `T[]`          | Returns truncated or zero-padded copy                                                               |
| `Arrays.copyOfRange(arr, from, to)` | `(arr, int, int)`        |          `T[]`          | Half-open slice copy `[from, to)`                                                                   |
| `Arrays.asList(T... a)`             | `(T... a)`               |        `List<T>`        | Fixed-size list wrapper backed by the array                                                         |

### Binary Search Contract & Deriving Insertion Points

```java title="BinarySearchContract.java"
int[] nums = {10, 20, 30, 40, 50};

int found = Arrays.binarySearch(nums, 30); // returns 2

// Search for 25 (absent, belongs at index 2):
int absent = Arrays.binarySearch(nums, 25); // returns -(2) - 1 = -3

// Derive the correct insertion point:
int insertionPoint = -absent - 1; // 2
```

### The `Arrays.asList()` Traps

```java title="AsListTraps.java"
// Trap 1: Fixed-size list view backed by the original array
String[] names = {"Alice", "Bob"};
List<String> list = Arrays.asList(names);
// list.add("Charlie"); // Throws UnsupportedOperationException!
list.set(0, "Alex");   // Mutates the backing 'names' array!

// Trap 2: Primitive array autoboxing failure
int[] nums = {1, 2, 3};
List<int[]> badList = Arrays.asList(nums); // Size is 1! Contains int[] object!

// Idiomatic conversion of primitive int[] to List<Integer>:
List<Integer> goodList = Arrays.stream(nums).boxed().toList(); // Java 16+
```
