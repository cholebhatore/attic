## 1. Arrays Methods Toolkit

Methods provided by `java.util.Arrays` and native Java array runtime operations:

| Method                                     | Parameters                   |       Return Type       |  Complexity  | Description / Notes                                                 |
| :----------------------------------------- | :--------------------------- | :---------------------: | :----------: | :------------------------------------------------------------------ |
| `Arrays.sort(arr)`                         | `(int[] \| double[] \| ...)` |         `void`          | `O(n log n)` | Dual-Pivot Quicksort on primitive arrays (unstable)                 |
| `Arrays.sort(T[] a, Comparator c)`         | `(T[] a, Comparator c)`      |         `void`          | `O(n log n)` | TimSort on object arrays (stable, adaptive)                         |
| `Arrays.parallelSort(arr)`                 | `(arr)`                      |         `void`          | `O(n log n)` | Multi-threaded ForkJoinPool sort for arrays `> 8192` items          |
| `Arrays.binarySearch(arr, key)`            | `(arr, key)`                 |          `int`          |  `O(log n)`  | **Array must be sorted**. Returns index or `-(insertion_point) - 1` |
| `Arrays.fill(arr, val)`                    | `(arr, val)`                 |         `void`          |    `O(n)`    | Assigns `val` to every element slot                                 |
| `Arrays.fill(arr, from, to, val)`          | `(arr, int, int, val)`       |         `void`          |    `O(k)`    | Fills half-open subrange `[from, to)` with `val`                    |
| `Arrays.equals(a, b)`                      | `(a, b)`                     |        `boolean`        |    `O(n)`    | Element-by-element equality check                                   |
| `Arrays.deepEquals(a, b)`                  | `(Object[], Object[])`       |        `boolean`        |  `O(R * C)`  | Recursively checks multidimensional array equality                  |
| `Arrays.toString(arr)`                     | `(arr)`                      |        `String`         |    `O(n)`    | Formats 1D array as `"[e1, e2, ...]"`; avoids `[I@hash`             |
| `Arrays.deepToString(arr)`                 | `(Object[])`                 |        `String`         |  `O(R * C)`  | Recursively formats nested 2D/3D matrices                           |
| `Arrays.copyOf(arr, newLen)`               | `(arr, int)`                 |          `T[]`          |    `O(n)`    | Returns zero-padded or truncated copy                               |
| `Arrays.copyOfRange(arr, from, to)`        | `(arr, int, int)`            |          `T[]`          |    `O(k)`    | Slices subrange `[from, to)` into a new array                       |
| `Arrays.mismatch(a, b)`                    | `(a, b)`                     |          `int`          |    `O(n)`    | Index of first differing element, or `-1` if identical (Java 9+)    |
| `Arrays.stream(arr)`                       | `(arr)`                      | `IntStream / Stream<T>` |    `O(1)`    | Converts primitive or object array to Stream                        |
| `Arrays.asList(T... a)`                    | `(T... a)`                   |        `List<T>`        |    `O(1)`    | Fixed-size list backed by original array; cannot `add`/`remove`     |
| `System.arraycopy(src, sp, dest, dp, len)` | `(src, int, dest, int, int)` |         `void`          |    `O(k)`    | JVM native memory copy (`memmove`); fastest array slice copy        |
| `arr.clone()`                              | `()`                         |          `T[]`          |    `O(n)`    | Deep copy for 1D primitive array; shallow copy for 2D/object array  |

## 6. Master Complexity Profile

| Data Structure       | Direct Access  |  Insert (Head)   |  Insert (Tail)   | Delete (Element) |          Contains          | Ordering Guaranteed |     Null Elements Permitted     |
| :------------------- | :------------: | :--------------: | :--------------: | :--------------: | :------------------------: | :------------------ | :-----------------------------: |
| **1D Array** (`T[]`) |     `O(1)`     |      `O(n)`      |  `O(n)` resize   |   `O(n)` shift   | `O(n)` / `O(log n)` sorted | Index order         |          Yes (objects)          |
| **`String`**         |  `O(1)` char   |        —         |        —         |        —         |         `O(n * m)`         | Immutable sequence  |               No                |
| **`StringBuilder`**  |  `O(1)` char   |   `O(n)` shift   | `O(1)` amortized |   `O(n)` shift   |         `O(n * m)`         | Mutable sequence    |        Appends `"null"`         |
| **`ArrayList`**      |     `O(1)`     |   `O(n)` shift   | `O(1)` amortized |   `O(n)` shift   |           `O(n)`           | Insertion order     |               Yes               |
| **`LinkedList`**     |     `O(n)`     |      `O(1)`      |      `O(1)`      |   `O(1)` node    |           `O(n)`           | Insertion order     |               Yes               |
| **`ArrayDeque`**     |     `O(1)`     | `O(1)` amortized | `O(1)` amortized |      `O(n)`      |           `O(n)`           | FIFO / LIFO         |       **No** (throws NPE)       |
| **`PriorityQueue`**  |  `O(1)` peek   |    `O(log n)`    |    `O(log n)`    |  `O(n)` search   |           `O(n)`           | Min/Max Heap        |       **No** (throws NPE)       |
| **`HashSet`**        |       —        | `O(1)` amortized | `O(1)` amortized | `O(1)` amortized |      `O(1)` amortized      | Unordered           |        1 `null` allowed         |
| **`TreeSet`**        |       —        |    `O(log n)`    |    `O(log n)`    |    `O(log n)`    |         `O(log n)`         | Sorted / Natural    |       **No** (throws NPE)       |
| **`HashMap`**        |   `O(1)` key   | `O(1)` amortized | `O(1)` amortized | `O(1)` amortized |         `O(1)` key         | Unordered           | 1 `null` key, any `null` values |
| **`TreeMap`**        | `O(log n)` key |    `O(log n)`    |    `O(log n)`    |    `O(log n)`    |       `O(log n)` key       | Sorted keys         |        **No null keys**         |
