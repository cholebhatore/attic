In Java, `String` is the universal datatype for text representation. Unlike primitive types or raw arrays, `String` instances are immutable objects backed by the JVM String Constant Pool and optimized under the hood with Compact Strings.

## Quick Comparison: Text Types in Java

| Feature              | `String`                                    | `StringBuilder`                             | `StringBuffer`                          |
| :------------------- | :------------------------------------------ | :------------------------------------------ | :-------------------------------------- |
| **Mutability**       | **Immutable** (all edits yield new objects) | **Mutable** (in-place buffer edits)         | **Mutable** (in-place buffer edits)     |
| **Thread Safety**    | Inherently thread-safe (read-only)          | Not thread-safe (fastest)                   | Thread-safe (`synchronized` methods)    |
| **Heap Storage**     | Heap + String Constant Pool                 | Heap only                                   | Heap only                               |
| **Performance**      | High allocation overhead in loops           | Optimal for single-threaded string assembly | Slower due to lock acquisition overhead |
| **JDK Availability** | Java 1.0+                                   | Java 5+                                     | Java 1.0+ (Legacy)                      |
| **Primary Use Case** | Fixed text, map keys, domain models         | Dynamic concatenation, algorithms, parsers  | Multi-threaded legacy shared logging    |
