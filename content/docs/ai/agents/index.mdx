Phase 10 made a single forward pass cheap. Everything in this phase spends that headroom on repetition: a model that calls tools, reads results, decides again, and keeps going until the task is done or the budget runs out.

An agent is not a smarter prompt. It is a control structure around a model, and the engineering that matters is in the structure: what the model can see, what it is allowed to do, when the loop stops, and how you know any of it worked. Five components, one loop, one protocol for the tools, and one evaluation harness. That is the whole phase, and each page takes one piece of it.

<Callout type="info">
  ### Frameworks are the least important thing here

Vendor frameworks come and go on an 18-month cycle, and the abstractions they sell are the parts you can least easily inspect. The five-component anatomy, the Think-Act-Observe loop with its budgets, the MCP contract, and the metric definitions outlive all of them. Read [Agent Frameworks](/ai/agents/agent-frameworks) to know what the options are and what each one hides, not to learn a framework. If you are going to build on one anyway, the [LangChain lessons](/ai/agents/agent-frameworks/langchain) walk it end to end and name the primitive behind each abstraction.

</Callout>

Read the anatomy block before anything else. Every later page assumes you hold the five-component model in your head and know that instructions, tool definitions and the trajectory are the same context window competing for the same tokens.

The tool and protocol block is where an agent stops being a demo: schemas, discovery, and the wiring between a model and an environment. The topology and security block is what breaks first when a single-agent loop is no longer enough. The evaluation block is the one people skip and the one that decides whether you can ship.

`agent-memory` and `agent-frameworks` can be read out of order. The first is a design essay about a component with no standard, the second is a map of a market that keeps moving.

## Prerequisites

- [Agentic RAG](/ai/rag/agentic-rag) for the retrieval-only version of the loop this phase generalizes to arbitrary tools
- [Prompt Chaining](/ai/rag/prompt-chaining) for the five workflow patterns that multi-agent topologies are built from
- [Context Budgeting](/ai/rag/context-budgeting) for the token accounting the loop's observation limits depend on
- [Schema Enforcement](/ai/rag/context-engineering) for grammar-constrained decoding behind strict tool arguments
- [Production Debugging](/ai/rag/production-debugging) for retrieval failure triage, which becomes one span type in an agent trace
- [Hybrid Search](/ai/rag/hybrid-search) and [Reranking](/ai/rag/reranking) for the retrieval components that context precision and recall score
- [Decoding Strategies](/ai/llm/decoding) for why temperature makes an agent trajectory non-deterministic across runs
- [Tokenization](/ai/llm/tokenization) for the token counts that budgets, costs and truncation are all measured in
- [Serving Engines Compared](/ai/inference/serving-engines) for structured output decoding, which is what enforces a tool's JSON Schema
- [Continuous Batching](/ai/inference/continuous-batching) for why a long-horizon agent occupies a slot for minutes, not seconds
- [Policy Optimization](/ai/reinforcement-learning/ppo) for the reward signal in Reflexion-style self-critique, which is judgment and not gradient

No page in this phase requires a GPU, a framework install, or a paid API key to read. Code samples are written from knowledge against provider SDKs and are not executed here.

## What you should be able to do afterwards

- Name the five components of an agent and say which of them are just tokens in the same context window
- Compute the re-send cost of a trajectory and explain why it grows quadratically in step count
- Describe an Agent Skill's three disclosure tiers and say when to use one instead of RAG or a fine-tune
- Write a tool definition with a description that routes, and say which of its three fields the model actually reads
- Explain the Think-Act-Observe loop and where each of its three phases fails in practice
- Size a step budget from a task's shape, and state the four stopping conditions a production loop needs
- Compute the cascading-error ceiling: a 95 percent per-step success rate over 20 steps
- Implement a stuck-action detector and say the three signals it checks
- Distinguish short-term from long-term memory and give an example of each long-term type
- Explain why contradiction is harder than similarity for memory writes
- Reproduce a ReAct trace in the Thought-Action-Observation format, and name its modern function-calling equivalent
- Choose between ReAct, Plan-and-Execute and Reflexion for a stated task, and say what the plan buys and costs
- State the condition Reflexion needs to work at all, and name the paper that says it does not always hold
- Contrast function calling with MCP in one sentence each, and say which one a model participates in
- Walk the MCP triad and explain the 1-to-1 client-server constraint
- Name the three server primitives by who controls them, and the three client primitives by direction
- Say what changed between MCP 2025-03-26, 2025-06-18, 2025-11-25 and 2026-07-28
- Explain the confused deputy problem in an MCP server that holds backend credentials
- Contrast `Prompt | LLM | Parser` with a cyclical stateful graph, and say which agent requirement forces the cycle
- Resume a LangGraph run from a checkpoint, and use `interrupt()` for an approval gate
- State which code in a node re-runs on resume and why that matters
- Compare supervisor, orchestrator-worker and handoff topologies on state, cost and debuggability
- Recite the multi-agent cost multipliers and the token arithmetic behind them
- Define the lethal trifecta and name a non-obvious exfiltration channel
- Rank least privilege, confirmation gates, sandboxing and prompt-level defenses by what survives a classifier miss
- Compute a BLEU score's components, name its brevity penalty, and state what it cannot see
- Explain why ROUGE is recall-oriented and BLEU precision-oriented, and what both share
- Read a benchmark number as an interval and say how many questions are behind it
- Distinguish Elo from Bradley-Terry and say which one a modern arena leaderboard fits
- Explain Cohen's kappa and what a Krippendorff alpha of 0.4 tells you about your annotators
- Name the four LLM-as-a-judge biases and the mitigation for each
- Write a swap-order judge call and explain why a tie is the informative outcome
- Define the four retrieval metrics, and diagnose a pipeline from their combination
- Explain how RAGAS computes faithfulness and why answer relevance uses a reverse-question trick
- Score an agent trajectory on tool selection, argument validity, step efficiency and task completion
- Assert a terminal state instead of comparing text, and say why that is the biggest quality jump available
- Decide which metrics belong in a pre-merge gate and which belong in a nightly run
- Name the attributes every generation span should carry, and say why retrieval deserves its own span
- Compare LangSmith, Langfuse and Phoenix on what each is for
- Place guardrails at six positions in an agent and identify the two an agent adds over a chatbot
- Choose between masking, pseudonymisation and synthetic replacement for a PII field
- Build a grounding check and state the three design choices that decide whether it is usable
