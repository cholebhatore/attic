LangChain is a thin standard layer between application code and everything an LLM application touches: the model provider, the prompt, the tools, the index, and the trace log. This series builds an application out of those pieces, one lesson at a time, and marks at every step what the framework actually provides against what would have to be written by hand.

Every lesson uses `uv` for packages and a Google Gemini key, available free from Google AI Studio. Swap the model class for any provider integration and the rest of the code is unchanged, which is the point of the layer.

Lessons 1 to 4 are the core: what the abstractions are, how a model is called, how output becomes typed data, and how pieces compose. ## Outcomes

- Explain what LangChain provides and what stays the developer's own code
- Set up a pinned project with `uv add` and run it with `uv run`
- Turn a model's free text into a validated Pydantic object, and handle the run where it does not
- Compose prompt, model, and parser into one runnable object that batches, streams, and runs async for free
- Build a tool-using agent with `create_agent`, and bound it with a step budget and a middleware stack
- Wire a retrieval chain from loader to retriever, and name the stage each failure lives in
- Ship it behind FastAPI with tests, tracing, retries, and a cache
