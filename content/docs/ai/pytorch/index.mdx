Phase 1 built the math. This phase puts it on hardware. A PyTorch tensor is the same array you already know, plus three things that change how you reason about it: a device, a dtype, and a stride layout that decides whether an operation copies memory or just relabels it.

Everything after this point in the curriculum, from transformers to distributed training, is these nine pages applied at larger scale.

## Prerequisites

Phase 1 covers the math these pages assume. Three of them in particular:

- [Vectors and Matrices](/ai/math-foundations/vectors-and-matrices) for rank, SVD, and what a weight matrix does geometrically
- [Tensor Broadcasting](/ai/math-foundations/tensor-broadcasting) for the stride and contiguity model PyTorch inherits
- [Backprop from Scratch](/ai/math-foundations/backprop-from-scratch) for the reverse-mode traversal that `autograd` automates

Install PyTorch with `uv`, matching the CUDA build to your driver:

```bash title="CPU only"
uv add torch torchvision --index-url https://download.pytorch.org/whl/cpu
```

```bash title="CUDA 12.6"
uv add torch torchvision --index-url https://download.pytorch.org/whl/cu126
```

Check what you got:

```python title="check_install.py"
import torch

print(torch.__version__)
print(torch.cuda.is_available())
print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else "cpu only")
```

The companion packages used later in this phase:

```bash
uv add safetensors einops webdataset
```

## Canonical resources

- [`pytorch/examples`](https://github.com/pytorch/examples) — official reference implementations, including the canonical ImageNet and language-modeling training loops
- [`pytorch/tutorials`](https://github.com/pytorch/tutorials) — the source for the PyTorch docs tutorials, kept in sync with releases
- [`arogozhnikov/einops`](https://github.com/arogozhnikov/einops) — named-axis tensor reshaping, covered in [Combining and Permuting](/ai/pytorch/combining-and-permuting)
- [`huggingface/safetensors`](https://github.com/huggingface/safetensors) — the zero-copy serialization format covered in [Checkpointing](/ai/pytorch/checkpointing)
- [Practical Deep Learning for Coders](https://course.fast.ai) — Jeremy Howard's course, which builds the same training harness from the outside in
- PyTorch docs on [Automatic Mixed Precision](https://docs.pytorch.org/tutorials/recipes/recipes/amp_recipe.html) and [TorchInductor](https://docs.pytorch.org/docs/stable/torch.compiler.html)
