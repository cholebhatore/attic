Phase 7 ended with a merged model behind a serving engine. Supervised fine-tuning can teach a model a format and a domain, and it cannot teach it to be right. The training signal is a fixed label per token, so the model is optimized for resemblance to the data rather than for the outcome the data was meant to produce.

This phase is about optimizing the outcome directly. The first three pages are classical reinforcement learning, which is where every LLM alignment algorithm comes from. The middle three are RLHF: the reward model, PPO, and DPO. The last three are the reasoning era: GRPO, verifiable rewards, and the systems that run them at scale.

New to reinforcement learning? Start with [RL Basics](/ai/reinforcement-learning/rl-basics). It explains RL in plain words and how it differs from supervised learning, defines the vocabulary, runs a policy-gradient learner in 20 lines of NumPy, shows why LLMs need RL after supervised fine-tuning and what state, action, and reward mean for a language model, and maps every algorithm in the phase. Every page after it also opens with a **plain-language version**: where the page sits, a short explanation with an analogy, the page's topics in order, and a table of the words it uses.

<Callout type="info">
  ### Every formula here is the one the papers use

The Bellman equations, the REINFORCE gradient, the PPO clipped surrogate, the Bradley-Terry loss, the DPO closed form, and the GRPO group advantage are written in the exact shape their source papers give them, with the arXiv id beside each. The reported numbers, such as R1-Zero at 47.0 pass@1 on AIME 2024 and DAPO-32B at 50 percent, are quoted from those papers rather than estimated.

</Callout>

Read RL Basics first: it is the map for the phase. Then read the classical block, even if you only care about LLMs. PPO is a policy gradient with a trust region, GRPO is PPO without a critic, and DPO is a reward model solved in closed form. - [What is an LLM](/ai/llm/what-is-an-llm) for the per-parameter memory arithmetic behind the four-model budget

## What you should be able to do afterwards

- Explain in plain words how RL differs from supervised learning, why LLMs need it after SFT, and how RLHF differs from RLVR
- Write an MDP for a language model and say where the discount factor goes and why it is usually 1
- State both Bellman equations and explain what the optimality one assumes that the expectation one does not
- Explain experience replay and the target network, and name the instability each one fixes
- Derive the REINFORCE gradient from the log-derivative trick and prove a baseline leaves it unbiased
- Write the PPO clipped surrogate, explain the min, and say why the clip range is effectively asymmetric
- Compute the memory budget for a PPO run at a given model size and name what each of the four models holds
- Derive DPO from the closed-form optimal policy and explain where the partition function cancels
- Compute the group-relative advantage and state why the group mean is a legal baseline
- Name DAPO's four fixes and Dr. GRPO's two removed biases, and what failure each one addresses
- List four verifiable reward sources and say what breaks if answer extraction is wrong
- Describe the four stages of the DeepSeek-R1 pipeline and what each one is for
- Distinguish pass@1, majority vote and best-of-N, and say which one a benchmark number is
- Pick a framework for a stated cluster size and model size, and name the six metrics to log
