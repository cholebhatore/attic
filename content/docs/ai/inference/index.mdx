Phase 9 assembled the right context and Phase 8 made the model reason. Neither says anything about the cost of running it. This phase is the hardware and systems layer: what a decode step spends, how much of that spend is avoidable, and what the engines that serve at scale do about it.

The whole phase reduces to one observation. Autoregressive decode reads every weight in the model to produce one token, so tokens per second is memory bandwidth divided by bytes per token. Almost every technique here is an attack on one of those two quantities: quantization shrinks the bytes, batching amortizes the read across streams, speculation produces more tokens per read, and SRAM-first silicon buys more bandwidth.

New to this phase? Start with [Inference Basics](/ai/inference/inference-basics). It defines the serving metrics, works out by hand why generating text is limited by memory bandwidth and how batching changes that, lays out the inference stack from silicon to API, and maps every optimization lever to its page. Every page after it also opens with a **plain-language version**: where the page sits, a short explanation with an analogy, the page's topics in order, and a table of the words it uses.

<Callout type="info">
  ### Every number here is published or derived

Hardware specifications come from vendor datasheets and architecture papers, with the source named next to the figure. Cost arithmetic is shown as arithmetic, from stated inputs, so you can redo it for your own model and GPU. Vendor throughput claims are labelled as vendor claims and distinguished from third-party measurements, which matters because only some of them are independent.

</Callout>

## What you should be able to do afterwards

- Explain in plain words why LLM decoding is limited by memory bandwidth, compute the single-sequence speed ceiling for a model on a GPU, and name the levers that raise throughput
- Walk the GPU execution hierarchy from thread to warp to block to SM, and say what limits each level
- Place an operation on a roofline from its arithmetic intensity and a GPU's ridge point, and predict whether it is compute-bound or bandwidth-bound
- Compute the batch-1 decode ceiling for any model and GPU from bandwidth and weight size
- Explain why a decode step uses 0.34 percent of an H100's BF16 capacity, and why batching is the fix
- Read a fused CUDA kernel: warp shuffles, shared memory, the two synchronization barriers, and what the strided loop is for
- Say when to write a Triton kernel instead of a CUDA one, and name the three Triton gotchas
- Explain FlashAttention's tiling and the online-softmax rescale well enough to say why it removes quadratic HBM traffic
- Compare LPUs, wafer-scale engines, TPUs and tiered-memory designs on what each trades, and state the four objections to SRAM-first silicon
- Convert between a floating-point range and its INT8 or INT4 representation using scale and zero-point
- Compute the quantization error variance and say what one fewer bit costs in decibels
- Distinguish per-tensor, per-channel and per-group quantization, and compute the effective bits per weight for a grouped scheme
- Explain the outlier problem and the three responses to it: mixed precision, smoothing, and rotation
- Walk through GPTQ's objective and Hessian, and say why AWQ protects salient channels instead
- Explain the straight-through estimator and why QAT needs it
- Say why QLoRA is not quantization-aware training
- Read a GGUF header, and compute bits per weight for any llama.cpp quant type from its block struct
- Estimate CPU and Apple Silicon decode ceilings from memory bandwidth
- Compute the KV cache bytes per token for any model from its config, and the number of concurrent sequences a GPU supports
- Find the context length at which KV reads overtake weight reads during decode
- Compare FP8 KV cache, INT4 KV cache, and token eviction on what each costs in quality and where each fails
- Explain why attention sinks must survive eviction
- Decompose end-to-end latency into TTFT and TPOT and name the lever for each
- Compute both prefill terms and the context length where attention work overtakes the projections
- Derive prefill and decode arithmetic intensity and explain why they scale with different variables
- Explain speculative sampling's accept-and-resample rule and why it preserves the target distribution exactly
- Compute expected tokens per verification pass and the speedup after draft cost
- Say when speculative decoding reduces throughput and why
- Explain iteration-level scheduling, selective batching, and why continuous batching requires paged KV cache
- State the four conditions for a prefix cache hit and the prompt-ordering rule that follows
- Compute whether prefill-decode disaggregation pays for a stated prompt length and interconnect
- Compare vLLM, SGLang, TensorRT-LLM and `llama.cpp` on build step, memory management, and what each is best at
- Explain what a CUDA graph eliminates and why static shapes force engines to capture many of them
- Describe how grammar-constrained decoding masks logits and why it changes the sampling distribution
