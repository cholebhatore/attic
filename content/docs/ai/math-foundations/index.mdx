Every model in this curriculum reduces to matrix multiplications and gradient updates. This phase builds intuition for both halves: how vectors and matrices represent and transform data, and how derivatives drive optimization.

<Callout type="info">
  No framework is required until the last page, where you build a working autograd engine in pure
  Python and NumPy. After that, the chain rule is code you have written rather than a formula you
  have read.
</Callout>

---

## Prerequisites

Phase 0 covers the Python used throughout these pages: list and dict mechanics, functions with type hints, and classes. The autograd implementation on the last page is a class with operator overloading, so `classes-and-oop` is worth reading first.

NumPy is the only external dependency. Install it with `uv`:

```bash
uv add numpy
```
