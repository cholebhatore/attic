Every model in this curriculum reduces to matrix multiplications and gradient updates. This phase builds intuition for both halves: how vectors and matrices represent and transform data, and how derivatives drive optimization.

---

## The one loop this phase explains

Every model you will ever train runs the same four steps, over and over. Here they are in plain words, using a language model as the example:

1. **Turn the input into numbers.** A sentence becomes a list of numbers per token: 768 for a small model like BERT-base, 4096 for a 7-billion-parameter one. Those lists are vectors, and stacking one per token gives a matrix.
2. **Push the numbers through the model.** Each layer is a matrix multiply followed by a <Tip term="non-linearity">A function like ReLU or sigmoid applied to each number, which bends the result. Without it, stacking matrix multiplies collapses into one matrix multiply.</Tip>. The final layer outputs one raw score per possible next token. Those scores are logits.
3. **Turn the scores into probabilities and measure the mistake.** Softmax converts scores into a distribution that sums to 1. A loss function then reduces "how wrong was that?" to a single number.
4. **Ask every weight which way to move, and nudge it.** One derivative per weight, collected into a gradient, multiplied by a learning rate, subtracted. Then go back to step 1 with the next batch.

Nothing in the rest of this curriculum is more than a larger version of that loop, and every page below is one of its four steps written out in full.

## How to read these pages

Three habits carry the phase, and they matter more than the order you read in:

- **Run every code block.** Each one prints its own answer, and the printed numbers are what the prose is really describing. A snippet that surprises you is a better signal than a paragraph you skimmed.
- **Check the geometry with two numbers.** When a page claims something about angles, lengths, or which way a weight should move, plug in a vector like `[1, 2]` and verify it by hand. Every claim on these pages survives that test, and the ones you test stop feeling like claims.
- **Treat confusion as a symbol problem first.** Most sentences on these pages are hard because one glyph in them was never expanded, not because the idea is difficult. [Notation and Symbols](/ai/math-foundations/notation-and-symbols) is the lookup table for that.

## The whole phase, topic by topic

Every heading in this phase, in reading order, with the one detail that makes each worth remembering. Read it before the pages to see where you are going, or after them as a revision sheet. Each accordion is one page, and the formulas are the ones you should be able to reproduce from memory.

<Accordions>
  <Accordion title="AI Basics">

    - **The field map** — AI contains ML contains deep learning; NLP and computer vision are fields defined by the data, LLMs are where NLP is today
    - **Data** — example, feature, label, and the train, validation, test split; leakage makes a test score measure memory
    - **Kinds of learning** — supervised, unsupervised, self-supervised (how LLMs pretrain), reinforcement; classification versus regression
    - **The model** — parameters are learned, hyperparameters are chosen; a layer is `y = Wx + b` plus an activation
    - **Training and inference** — forward, loss, backward, update; batch, step, epoch; overfitting shows as validation loss rising
    - **Language: from text to vectors** — corpus, token, vocabulary, one-hot, embedding; text becomes IDs becomes vectors
    - **Where embeddings come from: GloVe** — a co-occurrence matrix where `cat` and `dog` score 0.75 cosine without ever sharing a sentence
    - **Static versus contextual embeddings** — GloVe gives `bank` one vector; BERT computes it from the sentence; LLMs use both
    - **Language models and transformers** — next-token prediction, attention, context window, BERT versus GPT
    - **The tools** — NumPy, tensors, PyTorch, GPUs
    - **Where each word becomes math** — which later page opens up each term

  </Accordion>
  <Accordion title="Notation and Symbols">

    - **Scalars, vectors, matrices, tensors** — rank 0 through rank 4, and what each one represents in a model
    - **Shapes, and how to read them** — `(8, 512)` is "8 rows of 512"; axis 0 is the batch, `axis=-1` is the last
    - **The operators** — `@` is matrix multiply, `*` is element-wise, `.T` is transpose, `||v||` is length
    - **Reading a shape equation** — predict the output shape of a line before running it, and catch a wrong broadcast that way
    - **Subscripts, superscripts, and indices** — telling `x_i` (entry i) from `x^2` (a power) from `W^{T}` (a label, not a power)
    - **Greek letters and their jobs** — `lambda` for eigenvalues, `eta` for learning rate, `theta` for angles, `epsilon` for tiny steps
    - **The letters that stand for sizes** — `B` batch, `V` vocabulary, `K` classes, `d` width, `T` tokens
    - **Intervals, arrows, and comparison marks** — `[0, 1]` includes the ends, `(0, 1)` excludes them
    - **Big-O** — what `O(N^2)` promises about growth, and what it deliberately does not say about constants
    - **Words that are load-bearing** — the vocabulary a sentence collapses into, like "vanishes", "materialize", "downstream"
    - **Three formulas, expanded** — `A @ v = lambda * v`, the softmax, and `dW = dY.T @ X`, term by term

  </Accordion>
<Accordion title="Vectors and Matrices">

    - **Vectors as data and as geometry** — the same list of numbers is a record and an arrow
    - **Unit vectors and basis vectors** — length 1; the basis is the set of axes the coordinates are measured against
    - **Dimensionality** — the count of values, and the number that dominates every cost calculation later
    - **Matrices as linear transformations** — `y = Ax` maps `R^n` to `R^m`; a matrix is a recipe, not a container
    - **The affine layer** — `y = Wx + b`, why `nn.Linear` stores one row of `W` per output unit, and where the `.T` comes from
    - **Rank and invertibility** — rank counts the genuinely new column directions; short rank crushes space, so no inverse exists
    - **Eigen-decomposition** — `Av = lambda * v`: the directions a matrix only scales, never rotates; eigenvalues describe conditioning
    - **Singular value decomposition** — `A = U Sigma V^T`, works on any shape: rotate, stretch, rotate
    - **Low-rank approximation** — keep the top `k` singular values and no other rank-`k` choice can beat it (Eckart-Young); the seed of LoRA

  </Accordion>
<Accordion title="Similarity and Norms">

    - **The dot product** — multiply matching positions, add them up; a score of agreement, and `a . b = ||a|| ||b|| cos(theta)`
    - **A vector you can build yourself** — term frequency vectors, where the vocabulary sets the dimension and most entries are zero
    - **Projection** — the shadow one vector casts along another's direction
    - **Cosine similarity** — the angle with magnitude divided out, bounded in `[-1, 1]`
    - **Why unit normalization makes cosine free** — normalize once at index time and cosine becomes a plain dot product
    - **Distance metrics compared** — cosine distance `[0, 2]`, L2, L1, and raw dot product, sorted by whether stretching a vector changes the score
    - **L1 and L2 norms** — `||[3, -4]||_1` is 7, `||[3, -4]||_2` is 5; L2 punishes concentration, L1 does not
    - **Why norms become regularizers** — charge the model for a big weight vector and you get Lasso or Ridge
    - **Lasso and Ridge** — `L0 + lambda ||w||_1` versus `L0 + lambda ||w||_2^2`; the diamond corner zeroes weights, the circle only shrinks them
    - **The mechanism** — L1's push is `lambda * sign(w)` and never fades near zero; L2's push is `2 * lambda * w` and fades with the weight

  </Accordion>
<Accordion title="Derivatives and Gradients">

    - **Start here** — `L(w) = (w-3)^2`, one step of `w = w - eta * dL/dw`, and why the loss falls without knowing the curve
    - **The derivative** — the limit definition, secant versus tangent, and the sign table that decides which way to move a weight
    - **Partial derivatives** — hold every other variable frozen and measure one axis at a time
    - **Product, quotient, and chain rules** — the chain rule is the one that becomes backpropagation
    - **The gradient** — every partial in one vector; it points uphill, and its length is the steepness
    - **Directional derivatives** — `D_u f = grad(f) . u`, the rate of change along any direction you choose
    - **Jacobians** — every output against every input as a 2D table; knobs and speakers
    - **JVP versus VJP** — forward multiplies a tangent vector through, backward multiplies a cotangent vector through the transpose
    - **Stationary points** — read the Hessian's eigenvalues: all positive is a minimum, all negative a maximum, mixed signs a saddle

  </Accordion>
<Accordion title="Tensor Broadcasting">

    - **The problem broadcasting solves** — a nested loop and `X + b` produce identical numbers at very different speeds
    - **The three rules** — right-align the shapes, every dimension pair must match or contain a 1, missing leading dimensions count as 1
    - **Worked shape examples** — legal and illegal pairs, and the error message each one raises
    - **The unsqueeze idiom** — `[:, None]` adds a length-1 axis and turns two vectors into a whole matrix of pairs
    - **Strides, contiguity, and views** — a stride is the jump in memory for one step along an axis; `(3, 4)` with `stride = (4, 1)`
    - **View versus copy** — a view shares the same buffer and changes when you write through it; a copy does not
    - **Broadcasting with zero stride** — the stretch is a stride of 0, which is why it costs no memory
    - **Broadcasting in transformer code** — bias addition, positional encoding injection, and the causal attention mask
    - **Vectorization and performance** — the measured loop at 621.60 ms against 3.42 ms vectorized
    - **Accidental memory blowups** — an `O(N^2)` intermediate you never meant to materialize

  </Accordion>
<Accordion title="Softmax and Logits">

    - **Logits** — raw scores from `z = Wx + b`, unbounded, not probabilities, and named after log-odds
    - **The softmax function** — exponentiate, divide by the total, and the vector sums to 1
    - **Why exponentiate** — positivity, amplification of gaps, the clean `p - y` gradient, and the maximum-entropy argument
    - **Properties worth memorizing** — shift invariant, not scale invariant, order preserving
    - **Softmax or sigmoid** — competing classes versus independent labels, and why 2-class softmax is a sigmoid on the logit gap
    - **Temperature scaling** — `T` above 1 flattens, below 1 sharpens, and `T -> 0` is greedy decoding
    - **Numerical stability** — `exp(88)` is finite in `float32` and `exp(89)` is `inf`; `inf / inf` is `nan`, and `nan` spreads
    - **Log-softmax and log-sum-exp** — `log softmax(z)_i = z_i - LSE(z)`, computed by subtracting `max(z)` first
    - **Saturation and vanishing gradients** — a confident model produces gradients near 0.0002, and one confident mistake reaches 1.4140
    - **Why attention divides by `sqrt(d_k)`** — a dot product of `d_k` mean-zero unit-variance entries has variance `d_k`, so dividing by the root keeps it at 1
    - **Softmax over which axis** — always the vocabulary axis, which is `axis=-1`

  </Accordion>
<Accordion title="Information Theory and Loss">

    - **Surprise and information content** — `I(p) = -log(p)`, and `I(0.01) + I(0.01)` equals `I(0.0001)` at 9.210
    - **Entropy** — `H(p)`, the average surprise of a distribution under itself; the floor for any encoding
    - **Cross-entropy** — `H(p, q)`, where `p` supplies the weights and `q` supplies the surprise
    - **KL divergence** — `H(p, q) - H(p)`; asymmetric, not a metric, and minimized by maximizing likelihood
    - **The asymmetry matters** — mean-seeking versus mode-seeking, and the bimodal case where one direction is finite and the other is infinite
    - **Cross-entropy as the language modeling loss** — mean negative log-likelihood over the tokens of a batch
    - **The gradient is `p - y`** — why softmax plus cross-entropy collapses to predicted minus target, and why that is the whole reason training is cheap
    - **Perplexity** — `exp(H)`, the number of equally plausible choices a model is acting like it has, on a ratio scale

  </Accordion>
<Accordion title="Backprop from Scratch">

    - **The computational graph** — a directed acyclic graph of operations, with leaves, children, and an order
    - **Reverse-mode automatic differentiation** — one backward sweep for one output against a million inputs, versus one forward sweep per input
    - **A scalar autograd engine** — the `Value` class, operator overloading, and a `_backward` closure per node
    - **Why topological order matters** — a weight used twice gives `0.0` in the wrong order and `6.0` in the right one
    - **Training a small network** — the full forward, backward, and update trace on a 41-parameter, 406-node MLP
    - **Vectorized layer gradients** — `dX = dY @ W`, `dW = dY.T @ X`, `db = dY.sum(axis=0)`
    - **Gradient checking** — compare your backward pass against a centered finite difference, using relative error
    - **Choosing `eps`** — too large is truncation error, too small is catastrophic cancellation; the sweet spot lands near `3.45e-09`
    - **The zero_grad trap** — gradients accumulate by design, so forgetting to reset steers the model with last step's error

    </Accordion>

</Accordions>
