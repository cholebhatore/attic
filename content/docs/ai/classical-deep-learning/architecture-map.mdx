Every architecture in deep learning is a guess about the structure of the input. A dense layer assumes nothing. A convolution assumes nearby values belong together. A recurrent cell assumes order. Attention assumes any position may relate to any other. A graph network assumes the input is a set of entities plus a list of relationships. Choosing an architecture means matching that built-in assumption — its **inductive bias** — to the shape of the data.

A second, independent choice is the **goal**: predict an answer (discriminative), or generate new data (generative). This page puts the whole phase on one map and is meant to be read last, as a summary.

## The architecture map

| Architecture          | Core operation                                               | Inductive bias                                                 | Typical data                             | Canonical examples                                         | Covered in                                                                               |
| :-------------------- | :----------------------------------------------------------- | :------------------------------------------------------------- | :--------------------------------------- | :--------------------------------------------------------- | :--------------------------------------------------------------------------------------- |
| **MLP**               | Affine map then nonlinearity, layer after layer              | None; every input may interact with every other                | Fixed-size feature vectors, tabular data | House-price regression; the FFN inside a transformer block | [What Is a Neural Network](/ai/neural-networks/neural-network-basics)                    |
| **CNN**               | One small filter slid across a grid                          | Locality, translation equivariance                             | Images, spectrograms, any grid           | ResNet, U-Net                                              | [Convolutions](/ai/classical-deep-learning/convolutions)                                 |
| **RNN**               | One cell applied per step, hidden state carried forward      | Order; the same rule at every step                             | Sequences, time series                   | Char-RNN, early speech models                              | [Recurrent Neural Networks](/ai/classical-deep-learning/recurrent-networks)              |
| **LSTM / GRU**        | Recurrent cell with multiplicative gates                     | Order, plus a protected memory path                            | Longer sequences                         | Pre-2017 translation, speech recognition                   | [LSTM and GRU](/ai/classical-deep-learning/lstm-and-gru)                                 |
| **Transformer**       | Attention: every position mixes in every other, by relevance | Almost none; position must be injected                         | Text, image patches, audio, multimodal   | GPT, BERT, ViT                                             | [Transformers](/ai/transformers)                                                         |
| **GNN**               | Message passing along edges                                  | Permutation equivariance; relations given by the edge list     | Graphs: molecules, social, citation      | GCN, GraphSAGE, GAT                                        | [Graph Neural Networks](/ai/classical-deep-learning/graph-neural-networks)               |
| **Autoencoder / VAE** | Encode to a small code, decode back                          | The data lies near a low-dimensional manifold                  | Any                                      | Denoising AE, VAE, Stable Diffusion's VAE                  | [Generative Models](/ai/classical-deep-learning/generative-models#autoencoders-and-vaes) |
| **GAN**               | Generator against discriminator                              | None beyond the networks used                                  | Images mostly                            | DCGAN, StyleGAN                                            | [Generative Models](/ai/classical-deep-learning/generative-models#gans)                  |
| **Diffusion**         | Learned step-by-step denoising                               | Data can be reached from noise by small, nearly Gaussian steps | Images, audio, video                     | DDPM, Stable Diffusion                                     | [Generative Models](/ai/classical-deep-learning/generative-models#diffusion-models)      |

The top six rows are **backbones**: ways to turn an input into features. The bottom three are **generative frameworks**: training setups that wrap a backbone. A diffusion model's denoiser is usually a U-Net (a CNN) or a transformer (DiT). A GAN's generator and discriminator are usually CNNs. The two axes are independent, which is why "CNN versus GAN" is a category error.

## Choosing by data structure

Each backbone is a more general one with a constraint added, and the constraint is the inductive bias. The constraint saves parameters and data when it matches the input, and it gets in the way when it does not.

| Constraint added to a dense layer                                   | Result    | What it buys                                                            |
| :------------------------------------------------------------------ | :-------- | :---------------------------------------------------------------------- |
| Weights shared across positions, connections only to a local window | CNN       | 9.6 million position-tied weights become a few thousand shared ones     |
| Weights shared across time steps, state carried forward             | RNN       | Any sequence length with a fixed parameter count                        |
| Mixing weights computed from content instead of fixed               | Attention | Long-range relations without a recurrence chain                         |
| Mixing allowed only along given edges, weights shared across nodes  | GNN       | Arbitrary topology, any number of nodes, and node order does not matter |

A useful way to see this: a transformer is a GNN on a **complete** graph, where every token is connected to every other, and attention learns the edge weights. A CNN is a GNN on a **grid** graph, where each pixel is connected to its $k \times k$ neighborhood and the edge weights depend on relative position. A GNN keeps the message-passing machinery and takes the graph from the data.

Practical defaults, as of 2026:

| Data                               | First choice                                               | Why not the alternatives                                                               |
| :--------------------------------- | :--------------------------------------------------------- | :------------------------------------------------------------------------------------- |
| Tabular, under ~1M rows            | Gradient-boosted trees (XGBoost, LightGBM), then an MLP    | Trees still beat deep nets on most tabular benchmarks; MLPs need careful normalization |
| Images, small dataset              | Pretrained CNN or ViT, fine-tuned                          | A ViT from scratch needs far more data because it lacks the locality prior             |
| Text                               | Pretrained transformer                                     | RNNs cannot be parallelized over the sequence during training                          |
| Short, streaming time series       | GRU/LSTM, or a small transformer; also classical baselines | Constant memory per step matters on-device                                             |
| Molecules, networks, meshes        | GNN                                                        | Flattening a graph into a vector or sequence imposes an arbitrary node order           |
| Generating images, audio, or video | Diffusion (or flow matching)                               | GANs train unstably and cover fewer modes; VAEs alone give blurry samples              |

## Interview questions

<Accordions>
  <Accordion title="How should an architecture be chosen for a new dataset?">

    By matching the inductive bias to the structure of the data. Fixed-size vectors: an MLP, or gradient-boosted trees for tabular data. Grids where locality matters: a CNN. Sequences: a transformer, or an RNN when constant per-step memory matters. Entities with relationships: a GNN. Then separately decide whether the task is discriminative or generative, since autoencoders, GANs, and diffusion are training frameworks that wrap one of those backbones.
