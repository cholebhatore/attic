This module covers dependency workflows using `uv`, batch data in NumPy, data contract modeling with Pydantic and SQLAlchemy, and schema evolution through Alembic.

## Core stack architecture

Production Python stacks separate concerns across two layers: **runtime environment management** and **data persistence**.

| Layer                     | Traditional Tooling            | Modern Standard           | Role                                                                       |
| :------------------------ | :----------------------------- | :------------------------ | :------------------------------------------------------------------------- |
| **Package Installer**     | `pip`                          | `uv pip` / `uv add`       | Fetches wheels and resolves dependencies                                   |
| **Environment Isolation** | `virtualenv`, `venv`           | `uv venv`, auto `.venv`   | Isolates project packages from global site-packages                        |
| **Python Versions**       | `pyenv`                        | `uv python`               | Installs and pins specific Python runtimes                                 |
| **Project Declaration**   | `setup.py`, `requirements.txt` | `pyproject.toml`          | Declares project metadata and top-level dependencies                       |
| **Lockfile**              | `pip-compile`, `Pipfile.lock`  | `uv.lock`                 | Locks exact resolved dependency graph and checksums                        |
| **Numerical Arrays**      | Python `list`, `array` module  | NumPy `ndarray`           | Holds batched features, embeddings, and weights in contiguous typed memory |
| **API Data Contracts**    | Dicts, manual parsing          | Pydantic `BaseModel`      | Validates, serializes, and shapes HTTP/RPC input and output                |
| **Database Mapping**      | Raw SQL, legacy ORMs           | SQLAlchemy 2.0 / SQLModel | Maps relational tables to typed Python objects                             |
| **Schema Evolution**      | `create_all()`, manual scripts | Alembic                   | Versions and executes automated database migrations                        |
