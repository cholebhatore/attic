Python coordinates execution branching and iteration through whitespace indentation, English boolean operators, and concise collection comprehensions.

---

## 1. Conditionals and boolean operators

Blocks of code in conditional branches are indented 4 spaces after a colon `:`.

```python title="conditionals.py"
age = 20

if age >= 18:
    print("Adult")
elif age >= 13:
    print("Teenager")
else:
    print("Child")
```

### Operator mappings: Python vs TypeScript

| Logical Operation    | TypeScript / JavaScript    | Python               |
| :------------------- | :------------------------- | :------------------- |
| **Else If**          | `else if`                  | `elif`               |
| **Logical AND**      | `&&`                       | `and`                |
| **Logical OR**       | `\|\|`                     | `or`                 |
| **Logical NOT**      | `!condition`               | `not condition`      |
| **Value Equality**   | `==` or `===`              | `==`                 |
| **Value Inequality** | `!=` or `!==`              | `!=`                 |
| **Identity Check**   | `===` (reference equality) | `is`                 |
| **Membership Check** | `arr.includes(item)`       | `item in collection` |

<Callout type="warn">
  Use `==` to check value equality (e.g., `user["role"] == "admin"`). Use `is` to check object
  identity in memory, specifically when verifying singleton values like `None` (`if val is None:`).
</Callout>

## 2. Loops and iteration

### For loops

Python `for` loops iterate directly over the elements of any iterable object (lists, tuples, sets, strings, dictionaries):

```python title="loops.py"
users = ["Aryan", "Suhani", "Aditi"]

for user in users:
    print(user)
```

### Enumeration with `enumerate()`

To track element indices alongside their values, wrap the iterable in `enumerate()`:

```python title="enumerate.py"
for index, user in enumerate(users):
    print(f"Index {index}: {user}")
```

### Numeric ranges with `range()`

Generate integer sequences with `range(start, stop, step)`:

```python title="ranges.py"
for i in range(5):
    print(i)  # 0, 1, 2, 3, 4
```

### Dictionary iteration

```python title="dict_loops.py"
user = {"name": "Keshav", "role": "team_lead"}

for key, value in user.items():
    print(f"{key}: {value}")
```

### While loops

```python title="while_loop.py"
retries = 0
while retries < 3:
    print(f"Attempt {retries + 1}")
    retries += 1
```

## 3. Comprehensions

Comprehensions provide a compact syntax to transform or filter collections in a single expression.

### List comprehensions

```python title="list_comprehensions.py"
numbers = [1, 2, 3, 4, 5]

# Transform: map each number to its square
squares = [num ** 2 for num in numbers]
# [1, 4, 9, 16, 25]

# Filter: retain only even numbers
evens = [num for num in numbers if num % 2 == 0]
# [2, 4]
```

### Dictionary and set comprehensions

```python title="dict_set_comprehensions.py"
records = [
    {"id": 101, "name": "Suhani", "role": "engineer"},
    {"id": 102, "name": "Dhruv", "role": "engineer"},
]

# Create an ID-to-record lookup map
record_map = {r["id"]: r for r in records}

# Extract unique roles into a set
unique_roles = {r["role"] for r in records}
# {'engineer'}
```

<Callout type="info">
  Use comprehensions for straightforward transformations and filters. When logic requires multiple
  nested loops or complex error handling, write an explicit `for` loop to preserve readability.
</Callout>
