Python is a dynamically typed, high-level programming language that enforces indentation-based block scoping. For engineers with a TypeScript or JavaScript background, Python shares core programming paradigms while replacing curly braces with whitespace and offering distinct built-in primitives.

---

## Language execution model

Python executes through an interpreter that compiles source `.py` files into intermediate bytecode (`.pyc`), which is executed by the Python Virtual Machine (PVM).

- **No compilation step required**: Code runs directly via `python script.py` or through modern managers via `uv run script.py`.
- **Indentation as syntax**: Code blocks are delimited strictly by consistent indentation (standard convention is 4 spaces). Colons `:` initiate new blocks.
- **No line terminators**: Semicolons are not required at the end of statements.

```python title="syntax_structure.py"
# Indentation defines block hierarchy
def check_threshold(value: int) -> bool:
    if value > 100:
        print("Value exceeds threshold")
        return True
    return False
```

## Primitive data types

Variables are created upon assignment without variable declaration keywords (`const`, `let`, `var`).

```python title="primitives.py"
name = "Madhav"          # str (Unicode string)
age = 24                 # int (arbitrary-precision integer)
rating = 4.5             # float (double-precision IEEE 754)
is_active = True         # bool (True or False, capitalized)
result = None            # NoneType (represents absence of value)
```

### Comparison with TypeScript

| Dimension                | Python                        | TypeScript / JavaScript                   |
| :----------------------- | :---------------------------- | :---------------------------------------- |
| **Variable Declaration** | Direct assignment (`x = 10`)  | `const`, `let`                            |
| **Absence of Value**     | `None` (`NoneType`)           | `null`, `undefined`                       |
| **Booleans**             | `True`, `False`               | `true`, `false`                           |
| **Integers**             | `int` (unbounded capacity)    | `number` / `bigint`                       |
| **Floats**               | `float` (64-bit IEEE 754)     | `number`                                  |
| **String Formatting**    | f-strings: `f"Hello, {name}"` | Template literals: `` `Hello, ${name}` `` |

## Inspecting types

Python exposes runtime type inspection via `type()` and `isinstance()`:

```python title="type_inspection.py"
print(type(name))               # <class 'str'>
print(type(age))                # <class 'int'>
print(isinstance(rating, float)) # True
print(result is None)           # True
```

<Callout type="info">
  Always check for `None` using the `is` identity operator (`val is None`), not the equality
  operator (`val == None`). `is` tests memory reference against the singleton `None` object.
</Callout>
