A first-principles curriculum for AI engineering, moving from core programming pre-requisites and neural network architectures to production retrieval pipelines, autonomous agents, and evaluation harnesses.

<Callout type="info">
  This curriculum is organized into sequential modules. Part 0 establishes Python backend and data
  tooling. Part 1 breaks down the physical reality of Large Language Models. Subsequent modules
  cover prompt engineering, vector search, retrieval-augmented generation (RAG), multi-agent
  systems, and production LLMOps.
</Callout>

## Complete Curriculum Outline

### Part 0: Pre-requisites (Python & Persistence)

_Status: Implemented_

1. **Language fundamentals**: Python execution model, data structures, type hints, and OOP.
2. **Package management**: Project initialization, virtual environments, dependency resolution, and lockfiles with `uv`.
3. **Data modeling**: Validating API contracts with Pydantic and declaring relational tables with SQLAlchemy 2.0.
4. **Database persistence**: Object-Relational Mapping (ORM/ODM) patterns and schema migrations with Alembic.

---

### Part 1: LLM Foundations

_Status: Implemented_

1. **What is an LLM**: The two-file mental model (`model.py` and `parameters.bin`), demystifying weights and biases through house price prediction formulas, and scaling to billions of parameters.
2. **Model precision and sizing**: Understanding FP32, FP16, BF16, INT8, and INT4 precisions; calculating RAM and VRAM footprints using `params * bytes_per_param`.
3. **The inference lifecycle**: Step-by-step execution from raw text to token IDs, embedding vectors, transformer attention passes, logits, softmax sampling, and detokenization.
4. **Running models locally**: Executing open-weights models on local hardware without cloud APIs.

---

### Part 2: Prompt Engineering & In-Context Learning

1. **Core prompt mechanics**: System prompts, developer instructions, context windows, and token budgets.
2. **Structured outputs**: Constraining models to JSON schemas, Pydantic validation, and function signature parsing.
3. **Reasoning patterns**: Zero-shot, Few-shot, Chain-of-Thought (CoT), Self-Consistency, and ReAct frameworks.
4. **Prompt management**: Versioning, prompt drift, template engines, and preventing prompt injection attacks.

---

### Part 3: Embeddings & Vector Search

1. **Dense vector representations**: How text is mapped into continuous vector spaces.
2. **Similarity metrics**: Cosine similarity, Euclidean distance (L2), and Dot Product calculations.
3. **Vector indexing**: Exact nearest neighbors vs Approximate Nearest Neighbors (ANN) using HNSW and IVF.
4. **Vector databases**: Practical engineering with `pgvector`, Qdrant, Chroma, and Pinecone.

---

### Part 4: Retrieval-Augmented Generation (RAG)

1. **Document processing**: Semantic chunking, recursive character splitting, metadata preservation, and multi-format parsing.
2. **Hybrid search**: Combining dense semantic search with sparse lexical search (BM25).
3. **Re-ranking**: Improving retrieval precision with cross-encoders and re-ranking models (Cohere Rerank, BGE).
4. **Advanced RAG patterns**: Query transformation, hypothetical document embeddings (HyDE), context compression, and GraphRAG.

---

### Part 5: AI Agents & Tool Calling

1. **Tool execution & function calling**: Defining schemas, executing external functions, and feeding structured returns back to the model.
2. **Agent loops**: ReAct loops, state management, stopping conditions, and error recovery.
3. **Memory architectures**: Short-term conversational buffers, summary memory, and long-term vector-backed episodic memory.
4. **Multi-agent orchestration**: Supervisor-worker topologies, routers, handoffs, and parallel task execution.

---

### Part 6: Fine-Tuning & Open-Source Serving

1. **When to prompt vs fine-tune**: Evaluating data limits, domain adaptation, and cost trade-offs.
2. **Parameter-Efficient Fine-Tuning (PEFT)**: LoRA (Low-Rank Adaptation) and QLoRA mechanics.
3. **Dataset preparation**: Instruction-tuning format, cleaning data, and validation splits.
4. **High-throughput serving**: vLLM, PagedAttention, continuous batching, and local quantized inference with Ollama and GGUF.

---

### Part 7: Evaluation, Observability & LLMOps

1. **Evaluation frameworks**: Ground truth benchmarks, LLM-as-a-judge, and RAG triad metrics (faithfulness, answer relevance, context relevance via Ragas / DeepEval).
2. **Observability & tracing**: Tracing multi-step agent graphs and retrieval calls with OpenTelemetry, LangSmith, and Phoenix.
3. **Production optimization**: Semantic caching, prompt caching, fallback routing, rate limiting, and token cost tracking.
4. **Guardrails**: Input sanitization, hallucination mitigation, and output safety layers.

---

### Part 8: Capstone Engineering Projects

1. **Production Full-Stack Chat System**: End-to-end streaming chat application with authentication, session memory, and tool integration.
2. **Enterprise Knowledge RAG Engine**: Multi-tenant document indexing system with hybrid search, re-ranking, and automated evaluation metrics.
3. **Autonomous Coding Assistant**: Multi-step file-editing agent capable of reading repos, executing shell commands, and iteratively fixing bugs.
