Large Language Models (LLMs) often feel like magic until you look at the files sitting on disk. Underneath the conversational chat interfaces, an LLM boils down to two tangible pieces: a few hundred lines of model architecture code (`model.py`) and a massive binary file containing billions of learned floating-point numbers (`parameters.bin`).

<Callout type="info">
  This module breaks down LLMs from the ground up. We start with the physical anatomy of a model and
  how weights and biases work using an intuitive housing price formula, calculate memory footprints
  across precision levels, and trace how a prompt like `"he is a good"` travels through the
  end-to-end inference pipeline.
</Callout>
