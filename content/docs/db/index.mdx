A complete curriculum for database engineering, starting from operating system storage primitives and transaction theory to production SQL, schema migrations, and full-stack application data layers.

<Callout type="info">
  This curriculum is organized into sequential modules. Part 1 establishes the foundational mental
  models. Subsequent modules dive into storage engines, ACID internals, advanced SQL, ORM
  implementations, and production operations.
</Callout>

## Complete Curriculum Outline

### Part 1: Foundations

_Status: Implemented_

1. **What is a database**
   - Data, information, and persistence
   - Database vs file system vs spreadsheet vs in-memory store
   - DBMS vs database vs database server vs schema
2. **Why we need databases**
   - Concurrency and multi-user access
   - Integrity, consistency, and validation
   - Querying, indexing, and performance at scale
   - Durability, backup, and recovery
   - Security and access control
3. **Core concepts**
   - Records, fields, entities, relationships
   - Data modeling: conceptual, logical, physical
   - Schema-on-write vs schema-on-read
   - OLTP vs OLAP
   - Client-server architecture and connection basics
4. **The big picture flow**
   - App to driver to connection pool to DB server to storage engine to disk
   - Query lifecycle: parse, plan, optimize, execute, return
   - Where ORMs, ODMs, and migration tools fit in this flow

---

### Part 2: Database Theory Essentials

1. **ACID properties**
   - Atomicity, Consistency, Isolation, Durability
2. **Transactions**
   - BEGIN, COMMIT, ROLLBACK, savepoints
   - Isolation levels: read uncommitted, read committed, repeatable read, serializable
   - Anomalies: dirty read, non-repeatable read, phantom read, lost update, write skew
3. **Concurrency control**
   - Locking: shared, exclusive, row-level, table-level, deadlocks
   - MVCC (Multi-Version Concurrency Control)
   - Optimistic vs pessimistic concurrency
4. **Distributed concepts**
   - CAP theorem and PACELC
   - BASE and eventual consistency
   - Replication: leader-follower, multi-leader, leaderless
   - Sharding and partitioning
   - Consensus basics (Raft, Paxos at a high level)
5. **Storage internals**
   - Pages, heap files, row vs column storage
   - B-Tree and B+Tree
   - LSM trees, memtables, SSTables, compaction
   - Write-ahead log (WAL) and crash recovery
   - Buffer pool and caching

---

### Part 3: Types of Databases

1. **Relational (SQL)**: Model, strengths, weaknesses (PostgreSQL, MySQL, SQLite, SQL Server, Oracle)
2. **Document stores**: MongoDB, Couchbase, Firestore, embedding vs referencing
3. **Key-value stores**: Redis, DynamoDB, Memcached (caching, sessions, rate limits, queues)
4. **Wide-column stores**: Cassandra, ScyllaDB, HBase
5. **Graph databases**: Neo4j, property graph model, Cypher
6. **Time-series databases**: TimescaleDB, InfluxDB
7. **Vector databases**: Embeddings, similarity search (cosine, dot product, L2), ANN indexes (HNSW, IVF, PQ), pgvector, Pinecone, Qdrant, Weaviate, RAG pipelines
8. **Search engines**: Elasticsearch, OpenSearch, inverted index, full-text search
9. **Columnar and analytical (OLAP)**: ClickHouse, BigQuery, Snowflake, DuckDB
10. **NewSQL and distributed SQL**: CockroachDB, Spanner, TiDB
11. **Embedded and edge databases**: SQLite, libSQL/Turso, D1
12. **Multi-model and polyglot persistence**
13. **Selection matrix and architectural trade-off frameworks**

---

### Part 4: SQL in Depth

1. **SQL fundamentals**: Dialects, standards, DDL, DML, DQL, DCL, TCL, data types (numeric, text, boolean, date/time, UUID, JSONB, arrays, enums)
2. **Creating and defining structure**: CREATE/ALTER/DROP, constraints (PK, FK, UNIQUE, NOT NULL, CHECK, DEFAULT), sequences, identity columns, UUID vs serial vs ULID
3. **Querying data**: SELECT, WHERE, ORDER BY, LIMIT/OFFSET, filtering (LIKE, IN, BETWEEN, NULL semantics), aggregations (GROUP BY, HAVING), set operations (UNION, INTERSECT, EXCEPT)
4. **Modifying data**: INSERT, UPDATE, DELETE, UPSERT (ON CONFLICT), RETURNING clause, bulk COPY
5. **Joins and relationships**: 1:1, 1:N, M:N, INNER, LEFT, RIGHT, FULL, CROSS, SELF joins, cascading actions
6. **Advanced querying**: Subqueries, CTEs, recursive CTEs, window functions (ROW_NUMBER, RANK, LAG, LEAD), CASE expressions, JSON querying, keyset pagination
7. **Normalization and design**: 1NF, 2NF, 3NF, BCNF, denormalization criteria, schema patterns (soft deletes, audit trails, multi-tenancy, trees)
8. **Indexing and performance**: B-Tree mechanics, composite/partial/covering/expression indexes, index types (GIN, GiST, BRIN), EXPLAIN ANALYZE query plans, N+1 problem, PgBouncer pool sizing
9. **Programmability and objects**: Views, materialized views, stored procedures, functions, triggers, roles, privileges, Row-Level Security
10. **Transactions in practice**: SELECT FOR UPDATE, SKIP LOCKED, advisory locks, idempotency, retries
11. **Operations**: Backups (pg_dump, physical, PITR), read replicas, slow query monitoring, vacuum, and bloat management

---

### Part 5: Migrations

1. **Why migrations exist**: Schema drift, versioned schema management
2. **Migration concepts**: Up/down migrations, history tracking tables, state-based vs migration-based approaches, branching
3. **Safe migrations**: Additive changes, zero-downtime expand/contract patterns, safe NOT NULL column additions, concurrent index creation, DDL locks
4. **Workflow & CI/CD**: Staging environments, deploy pipelines, rollback limitations, seeding, baselining existing databases
5. **Tooling landscape**: Prisma Migrate, Alembic, Flyway, Liquibase, Knex, TypeORM, Drizzle Kit, Django migrations, Atlas

---

### Part 6: ORMs and ODMs

1. **Object-relational impedance mismatch**
2. **ORM architecture**: Active Record vs Data Mapper vs Unit of Work, query builders vs full ORMs vs raw SQL
3. **ODMs**: Mongoose and document mapping
4. **Benefits**: Type safety, productivity, portability, SQL injection prevention
5. **Pitfalls**: Leaky abstractions, N+1 queries, inefficient generated SQL, over-fetching
6. **Common patterns**: Models, eager vs lazy loading, transaction management, connection lifecycles
7. **Ecosystem landscape**: TypeScript (Prisma, Drizzle, TypeORM, Kysely, Mongoose) and Python (SQLAlchemy, SQLModel, Django ORM, Tortoise, Beanie)

---

### Part 7: Prisma (TypeScript/JavaScript) Hands-On

1. **Setup and architecture**: Installation, `prisma init`, datasource, generators, client engine, environment variables
2. **Schema modeling**: Fields, attributes (`@id`, `@unique`, `@default`, `@updatedAt`), enums, relations, referential actions, indexes
3. **Migration workflows**: `prisma migrate dev`, `deploy`, `reset`, `status`, `resolve`, `db push`, `db pull`, shadow databases, custom migrations, seeding
4. **Prisma Client queries**: CRUD operations, filtering, pagination, nested writes, aggregations, `$transaction`, `$queryRaw`, extensions, error handling
5. **Production concerns**: Connection pooling, serverless, logging, query performance, Prisma Studio
6. **End-to-end project**: Building a full API route with schema, migrations, and typed queries

---

### Part 8: SQLAlchemy and Alembic (Python) Hands-On

1. **SQLAlchemy foundations**: Core vs ORM, Engine, connection, session, declarative 2.0 typed mappings, relationships
2. **Querying**: `select()`, filters, joins, `selectinload` vs `joinedload`, transactions, raw SQL, async SQLAlchemy (`AsyncSession`), FastAPI dependency injection
3. **Alembic setup**: `alembic init`, `alembic.ini`, `env.py`, `target_metadata`, async configurations
4. **Alembic commands**: `revision -m`, `--autogenerate`, `upgrade`, `downgrade`, `current`, `history`, `stamp`, `merge`, offline SQL mode
5. **Manual migrations**: Operations (`op.create_table`, `op.add_column`), data migrations, SQLite batch mode, constraint naming conventions
6. **Production concerns**: CI/CD execution, test databases, common autogenerate pitfalls
7. **End-to-end project**: FastAPI + SQLAlchemy 2.0 + Alembic + PostgreSQL

---

### Part 9: NoSQL and Vector Databases in Practice

1. **MongoDB**: Documents, collections, BSON, CRUD, aggregation pipelines, indexes, Mongoose/Beanie examples
2. **Redis**: Data structures, caching patterns (cache-aside, TTL, write-through), pub/sub, streams, rate limiting, RDB/AOF persistence
3. **Vector databases**: Embeddings, pgvector setup, similarity queries (cosine, dot product, L2), HNSW/IVFFlat indexes, metadata filtering, chunking, RAG retrieval pipelines

---

### Part 10: Application-Level Database Engineering

1. **Data access patterns**: Repository pattern, service layers, DTOs vs persistence entities
2. **Multi-tenancy**: Shared schema, schema-per-tenant, database-per-tenant, Row-Level Security
3. **Caching architectures**: Multi-tier caching, cache invalidation, outbox pattern, event queues
4. **Authentication data modeling**: Users, sessions, refresh tokens, RBAC permissions
5. **Handling large datasets**: Archiving, table partitioning, cursor pagination at scale
6. **Security & compliance**: SQL injection prevention, parameterized queries, secret management, encryption, PII auditing
7. **Hosting & infrastructure**: RDS, Cloud SQL, Neon, Supabase, PlanetScale, Docker Compose local dev, backup verification
8. **Testing & observability**: Testcontainers, transaction rollback test fixtures, slow query logs, APM tracing

---

### Part 11: Capstone and Reference

1. **Capstone project**: Design, model, migrate, and query an end-to-end production system with Prisma and Alembic implementations
2. **Cheat sheets**: SQL, Prisma commands, Alembic commands
3. **Decision frameworks**: Database engine selection, ORM vs query builder evaluation, migration strategies
4. **Anti-patterns**: Common database design and query antipatterns
5. **Glossary & learning resources**
