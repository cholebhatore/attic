VS Code, Slack, Discord, Figma's desktop app, and 1Password are built with web technology inside a desktop shell. The shell provides windows, menus, file system access, and auto-updates; the UI is a web app.

---

## The plain-language version

A desktop web-tech app has two sides. The **main process** (or core) talks to the operating system: windows, files, tray, native menus. The **renderer** shows the UI in a web view. They communicate over **IPC** (inter-process communication), and the renderer should never get raw OS access.

| Word                            | Plain meaning                                                     |
| :------------------------------ | :---------------------------------------------------------------- |
| **main process**                | Privileged process controlling the app.                           |
| **renderer**                    | The web page showing the UI.                                      |
| **IPC**                         | Messages between processes.                                       |
| **preload script**              | Electron script that exposes a safe, limited API to the renderer. |
| **code signing / notarisation** | Proving to the OS who built the app.                              |

| Option                 | UI                                           | Backend language | Notes                               |
| :--------------------- | :------------------------------------------- | :--------------- | :---------------------------------- |
| Electron               | Bundled Chromium                             | Node.js          | Most mature; larger apps            |
| Tauri                  | OS web view (WebView2, WKWebView, WebKitGTK) | Rust             | Small binaries; also targets mobile |
| Wails                  | OS web view                                  | Go               | Similar to Tauri                    |
| .NET MAUI, Qt, Flutter | Native or own renderer                       | C#, C++, Dart    | Not web-based                       |
