## The plain-language version

Variables are names attached to objects. Every value is an object with a type, but variables themselves have no fixed type. The four core collections are **list** (ordered, changeable), **tuple** (ordered, fixed), **dict** (key to value), and **set** (unique items).

| Word                    | Plain meaning                                                |
| :---------------------- | :----------------------------------------------------------- |
| **dynamic typing**      | Types are checked at runtime; a name can point to any type.  |
| **mutable / immutable** | Can / cannot be changed in place.                            |
| **iterable**            | Anything a `for` loop can walk over.                         |
| **comprehension**       | One-line way to build a list, dict, or set from an iterable. |
| **truthy / falsy**      | Values treated as `True` / `False` in conditions.            |

## Values and strings

```python
count = 3                 # int (arbitrary precision: no overflow)
price = 19.99             # float (same pitfalls as JS numbers)
from decimal import Decimal
total = Decimal("19.99") * 3   # exact decimal for money
name = "Ada"
active = True
nothing = None

greeting = f"Hi {name}, {count} items in the cart"   # f-string
"a,b,c".split(",")        # ['a', 'b', 'c']
"  hi ".strip().upper()   # 'HI'
"ord" in "order"          # True
len(name)                 # 3
7 // 2, 7 % 2, 2 ** 10    # (3, 1, 1024): floor division, modulo, power
```

## Collections

```python
items = ["apple", "pear"]           # list
items.append("fig")
items[0], items[-1], items[1:3]     # first, last, slice

point = (3, 4)                      # tuple: fixed
x, y = point                        # unpacking

user = {"id": 1, "name": "Ada"}     # dict
user["email"] = "ada@example.com"
user.get("phone", "n/a")            # default if missing (no KeyError)
for key, value in user.items(): ...

tags = {"python", "web", "python"}  # set -> {'python', 'web'}
tags & {"web", "go"}                # intersection {'web'}
```

## Control flow

```python
if count > 10:
    tier = "bulk"
elif count > 0:
    tier = "normal"
else:
    tier = "empty"

for i, item in enumerate(items):    # index + value
    print(i, item)

for a, b in zip(names, scores): ... # pair up two lists

while retries < 3:
    retries += 1

match event:                        # structural pattern matching (3.10+)
    case {"type": "order", "id": order_id}:
        handle_order(order_id)
    case {"type": "refund"}:
        handle_refund(event)
    case _:
        log_unknown(event)
```

Note: `and`, `or`, `not` instead of `&&`, `||`, `!`. `==` compares values; `is` checks identity (use `is None`).

## Comprehensions

```python
squares = [n * n for n in range(5)]                 # [0, 1, 4, 9, 16]
evens = [n for n in nums if n % 2 == 0]
by_id = {u["id"]: u for u in users}                 # dict comprehension
total = sum(o.amount for o in orders)               # generator: no intermediate list
```

## Truthiness and mutability

Falsy: `False`, `None`, `0`, `0.0`, `""`, `[]`, `{}`, `set()`. Everything else is truthy, so `if items:` means "if the list is non-empty".

```python
a = [1, 2]
b = a           # same list, two names
b.append(3)     # a is now [1, 2, 3]
c = a.copy()    # shallow copy
```

<Callout type="warn">
  Mutable default arguments are shared across calls: `def add(x, items=[])` keeps one list forever.
  Use `items=None` and create the list inside the function.
</Callout>
