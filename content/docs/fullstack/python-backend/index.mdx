## Python for JavaScript developers

| JavaScript / Node                          | Python                                                     |
| :----------------------------------------- | :--------------------------------------------------------- |
| `npm`, `package.json`, `package-lock.json` | `uv`, `pyproject.toml`, `uv.lock`                          |
| `node_modules` per project                 | Virtual environment (`.venv`) per project                  |
| `const x = 1` / `let`                      | `x = 1` (no keyword; constants by `UPPER_CASE` convention) |
| `{ }` blocks                               | Indentation (4 spaces)                                     |
| `null`, `undefined`                        | `None`                                                     |
| `true` / `false`                           | `True` / `False`                                           |
| Array / Object / Map                       | `list` / `dict` / `dict`                                   |
| `arr.map(x => x * 2)`                      | `[x * 2 for x in arr]`                                     |
| Template literal `` `Hi ${name}` ``        | f-string `f"Hi {name}"`                                    |
| `async`/`await`, event loop built in       | `async`/`await`, `asyncio` loop started explicitly         |
| `try` / `catch` / `finally`                | `try` / `except` / `finally`                               |
| TypeScript types                           | Type hints + mypy or pyright                               |
| Zod                                        | Pydantic                                                   |
| Express / Fastify                          | FastAPI / Flask / Django                                   |
| Prisma / Drizzle                           | SQLAlchemy / Django ORM                                    |
| Jest / Vitest                              | pytest                                                     |
| ESLint + Prettier                          | Ruff                                                       |
