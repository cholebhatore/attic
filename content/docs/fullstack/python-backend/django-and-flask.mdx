FastAPI is not the only option, and often not the best one. A content-heavy product with an admin back office ships faster on Django; a tiny internal service may only need Flask.

---

## Django

A full framework with an opinion on everything.

| Built in         | What it gives                                                                 |
| :--------------- | :---------------------------------------------------------------------------- |
| ORM + migrations | Models in Python, `makemigrations` / `migrate`                                |
| Admin            | A complete CRUD back office generated from models                             |
| Auth             | Users, groups, permissions, sessions, password hashing                        |
| Forms, templates | Server-rendered HTML with CSRF protection                                     |
| Security         | CSRF, XSS escaping, clickjacking headers, SQL injection protection by default |

```python title="shop/models.py"
from django.db import models

class Order(models.Model):
    user = models.ForeignKey("auth.User", on_delete=models.CASCADE, related_name="orders")
    status = models.CharField(max_length=20, default="pending")
    created_at = models.DateTimeField(auto_now_add=True)
```

```python
Order.objects.filter(status="pending").select_related("user")[:20]   # join to avoid N+1
Order.objects.prefetch_related("items")                              # separate batched query
```

uv run django-admin startproject config .

APIs on Django: **Django REST Framework** (serializers, viewsets, permissions; most widely used) or **Django Ninja** (FastAPI-style type hints and Pydantic on Django).

## Flask

A micro-framework: routing, request/response, templates. Everything else (ORM, validation, auth) is an extension or a choice.

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

@app.post("/orders")
def create_order():
    data = request.get_json()
    return jsonify({"id": 1, **data}), 201
```

## Choosing

|             | FastAPI                                     | Django                                         | Flask                      |
| :---------- | :------------------------------------------ | :--------------------------------------------- | :------------------------- |
| Style       | Async-first API framework                   | Full-stack, batteries included                 | Minimal, assemble the rest |
| Validation  | Pydantic, built in                          | Forms / DRF serializers                        | Extension                  |
| Admin panel | No                                          | Yes, excellent                                 | Extension                  |
| Docs        | Automatic OpenAPI                           | DRF or Ninja for OpenAPI                       | Extension                  |
| Best for    | APIs, AI services, async I/O, microservices | Products with admin, content, many CRUD models | Small services, prototypes |

**Litestar** is another modern ASGI framework, similar to FastAPI with more built in (DTOs, channels).
