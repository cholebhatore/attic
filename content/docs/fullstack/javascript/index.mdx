React, Node.js, every bundler, and every browser API sit on JavaScript's runtime model. The bugs that take longest to find in those tools, such as stale closures, lost `this`, floating-point totals, unhandled rejections, circular imports, and XSS through `innerHTML`, come from the language and its execution model rather than from the frameworks.

## Afterwards

- Predict coercion and equality results, and handle money, large IDs, and Unicode correctly.
- Explain closures, the loop-with-var bug, stale closures, and every way `this` is bound.
- Explain prototype lookup, what `new` and `class` do, and prototype pollution.
- Order any mix of synchronous code, promises, `await`, and timers, and write bounded-concurrency async code with cancellation.
- Explain ESM vs CommonJS behaviour, live bindings, and circular import failures.
- Insert content without XSS, use event delegation, and handle `fetch` errors correctly.
