When an order is placed, the system must charge the card, send an email, update analytics, and notify the warehouse. Doing all of that inside the HTTP request makes the request slow and fragile; one failing step fails the order. A message broker lets the order service record the event once and lets each downstream task happen on its own schedule, with retries.

---

## The plain-language version

A **broker** is a post office between services. **Producers** drop messages off; **consumers** pick them up. The producer does not wait for the consumer, and either can be down for a while without losing messages.

| Word                    | Plain meaning                                                          |
| :---------------------- | :--------------------------------------------------------------------- |
| **producer / consumer** | Sends / receives messages.                                             |
| **queue**               | Messages consumed and removed; each goes to one consumer.              |
| **log / stream**        | Messages appended and retained; many readers track their own position. |
| **topic**               | Named category of messages.                                            |
| **ack**                 | Consumer confirms a message was processed.                             |
| **DLQ**                 | Dead-letter queue for messages that keep failing.                      |

---

## Benefits and costs

| Benefit                                                        | Cost                                            |
| :------------------------------------------------------------- | :---------------------------------------------- |
| Decoupling: producer does not know consumers                   | Harder to trace a request end to end            |
| Load levelling: consumers work at their own pace during spikes | Eventual consistency: results arrive later      |
| Resilience: retries, consumers can be down                     | Duplicates, ordering, poison messages to handle |
| Fan-out: many consumers react to one event                     | Another system to run and monitor               |
