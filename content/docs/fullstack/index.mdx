These notes follow a request from the network cable to the database row and back. Each section pairs the theory that explains why things behave the way they do with an implementation guide and the current tools for the job.

Cloud and DevOps depth lives in [Cloud](/cloud). Database internals live in [Databases](/db). The [AI Engineering](/ai) section covers models; [AI Integration](/fullstack/ai-integration) here covers putting them inside a web app.

<Callout type="info">
  Backend pages show Node.js and Python side by side where the idea is the same in both. The Python
  track starts from zero.
</Callout>
