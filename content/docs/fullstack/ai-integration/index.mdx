Most AI features in web apps are not model training; they are API calls wrapped in good engineering: keys kept on the server, responses streamed to the UI, outputs validated, costs capped, and failures handled. This section covers that engineering. How models work, fine-tuning, and agent design in depth live in [AI Engineering](/ai).

| Word                  | Plain meaning                                                                       |
| :-------------------- | :---------------------------------------------------------------------------------- |
| **token**             | Unit of text the model reads and writes, roughly three-quarters of an English word. |
| **context window**    | Maximum tokens per request (prompt + history + documents).                          |
| **system prompt**     | Instructions that frame the model's behaviour.                                      |
| **structured output** | Model response constrained to a JSON schema.                                        |
| **tool calling**      | Model asks the app to run a function and return the result.                         |
| **RAG**               | Retrieval-augmented generation: fetch relevant data, put it in the prompt.          |
| **embedding**         | Vector representing the meaning of text.                                            |
| **MCP**               | Model Context Protocol: standard way to expose tools and data to AI clients.        |
