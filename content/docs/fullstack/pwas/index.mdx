A Progressive Web App is a website that can be installed to the home screen, launch in its own window, work offline, and receive push notifications. No app store is required, and one codebase serves every platform.

---

## The plain-language version

Three pieces turn a site into a PWA:

1. **HTTPS**.
2. A **web app manifest**: name, icons, colours, start URL, display mode.
3. A **service worker**: offline support and push. See [Service Workers](/fullstack/performance/service-workers).

| Word               | Plain meaning                                          |
| :----------------- | :----------------------------------------------------- |
| **manifest**       | JSON file describing the installed app.                |
| **display mode**   | `standalone` hides the browser UI.                     |
| **install prompt** | Browser UI offering to install the app.                |
| **maskable icon**  | Icon with safe padding for adaptive shapes on Android. |

---

## Manifest

```json title="manifest.webmanifest"
{
  "name": "Attic Tasks",
  "short_name": "Tasks",
  "start_url": "/?source=pwa",
  "display": "standalone",
  "background_color": "#ffffff",
  "theme_color": "#0f766e",
  "icons": [
    { "src": "/icons/192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "/icons/512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "/icons/maskable.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ],
  "shortcuts": [{ "name": "New task", "url": "/tasks/new" }]
}
```

```html
<link rel="manifest" href="/manifest.webmanifest" />
```

## Platform reality

| Capability         | Android / desktop Chromium     | iOS / iPadOS Safari                     |
| :----------------- | :----------------------------- | :-------------------------------------- |
| Install            | Prompt (`beforeinstallprompt`) | Manual: Share, Add to Home Screen       |
| Push notifications | Yes                            | Yes, for installed web apps (iOS 16.4+) |
| Background sync    | Yes                            | No                                      |
| Storage            | Generous                       | Can be evicted after inactivity         |

PWAs can also be listed in the Play Store and Microsoft Store (via Bubblewrap / PWABuilder).

---

## PWA, native, or cross-platform?

A PWA is enough for content, productivity, and commerce apps. Native or [React Native](/fullstack/mobile) is needed for heavy device integration (Bluetooth on iOS, background location, widgets), App Store presence, or top-tier performance.
