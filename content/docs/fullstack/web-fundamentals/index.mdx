Every later section rests on these pages. A slow page, a hanging upload, a CORS error, a certificate warning, a DNS change that "has not propagated", or a deploy that drops connections usually traces back to one of the layers here. The material changes slowly: TCP's congestion control, the same-origin policy, and the rendering pipeline work the same way they did years ago, so it repays depth.
