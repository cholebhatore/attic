title: Overview
description: One application built end to end twice, with a Node.js backend and a Python backend, exercising every section from HTML to deployment and observability.
---

Reading about systems and building one are different skills. The capstone is a single product, an order-tracking and support app for a small online shop, built once with an Express backend and once with a FastAPI backend, sharing the same React frontend and the same API contract.

---

## What gets built

| Area             | Feature                                                                                  | Sections used                                                                                                                 |
| :--------------- | :--------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| Frontend         | Next.js storefront with SSG product pages, SSR search, client cart                       | [React](/fullstack/react), [Rendering](/fullstack/rendering), [Tailwind](/fullstack/tailwindcss)                              |
| Auth             | Email/password with refresh rotation, Google sign-in, admin role                         | [Auth](/fullstack/auth)                                                                                                       |
| API              | REST with OpenAPI, cursor pagination, idempotent order creation                          | [APIs](/fullstack/apis)                                                                                                       |
| Data             | PostgreSQL with migrations, indexes, transactions for stock                              | [Databases](/fullstack/databases)                                                                                             |
| Cache and limits | Redis for product cache, sessions, rate limits                                           | [Redis](/fullstack/redis), [Caching](/fullstack/caching)                                                                      |
| Async            | Order confirmation emails and webhooks via a job queue and outbox                        | [Message Brokers](/fullstack/message-brokers)                                                                                 |
| Real-time        | Live order status via SSE                                                                | [Real-time](/fullstack/realtime)                                                                                              |
| Search           | Product search with Postgres full-text + trigram                                         | [Search](/fullstack/search)                                                                                                   |
| AI               | Support assistant with RAG over help articles and an order-status tool                   | [AI Integration](/fullstack/ai-integration)                                                                                   |
| Quality          | Unit, integration, and Playwright tests in CI                                            | [Testing](/fullstack/testing)                                                                                                 |
| Ops              | Docker images, Compose locally, deploy to a VPS or PaaS, OpenTelemetry traces, SLO alert | [Containers](/fullstack/containers), [Deployment](/fullstack/deployment), [Building for Scale](/fullstack/building-for-scale) |
