Tailwind replaces writing CSS files with composing small single-purpose classes in markup. It looks noisy at first; the payoff is no naming, no dead CSS, and styles that live next to the element they style.

---

## The plain-language version

Each class does one thing: `p-4` is padding, `text-sm` is font size, `md:flex` is "flex from the medium breakpoint up". Tailwind scans the source files for class names and generates only the CSS that is used.

| Word                | Plain meaning                                                            |
| :------------------ | :----------------------------------------------------------------------- |
| **utility class**   | A class that sets one or two properties.                                 |
| **variant**         | A prefix that applies a utility conditionally: `hover:`, `md:`, `dark:`. |
| **theme**           | The design tokens (colours, spacing, fonts) utilities are built from.    |
| **arbitrary value** | One-off value in brackets: `w-[37rem]`.                                  |

---

## Why utility-first

| Traditional CSS                      | Utility-first                        |
| :----------------------------------- | :----------------------------------- |
| Invent class names                   | No naming                            |
| CSS grows forever; deleting is risky | Unused utilities are never generated |
| Styles in another file               | Styles on the element                |
| Specificity conflicts                | All utilities have equal specificity |

The cost: long class lists and a learning curve. Repetition is handled by components, not by `@apply`.

---

## v4 setup

```css title="app.css"
@import 'tailwindcss';

@theme {
  --color-brand-500: oklch(62% 0.17 160);
  --font-display: 'Inter', sans-serif;
  --breakpoint-3xl: 120rem;
}
```

Tailwind v4 is configured in CSS (`@theme`) rather than `tailwind.config.js`, detects source files automatically, and every token becomes a CSS variable (`var(--color-brand-500)`). It runs as a Vite plugin (`@tailwindcss/vite`) or PostCSS plugin (`@tailwindcss/postcss`).

## Variants

```html
<button
  class="rounded-lg bg-brand-500 px-4 py-2 text-white
         hover:bg-brand-600 focus-visible:outline-2
         disabled:opacity-50 md:px-6 dark:bg-brand-400"
>
  Save
</button>
```

Also `group-hover:` (react to a parent), `peer-invalid:` (react to a sibling), `@container` queries (`@md:`), `aria-expanded:`, and `data-[state=open]:`.
