Deployment is getting a specific version of the code running for users, safely and repeatably. This section covers the basic paths an application developer owns. Cloud architecture in depth (VPCs, IAM, managed services) is in [Cloud](/cloud).

<Mermaid
  chart={`
flowchart LR
    G["git push"] --> CI["CI: lint, test, build image"] --> R["Registry"]
    R --> S["Staging deploy + smoke tests"] --> P["Production: rolling or canary"]
    P --> M["Monitor SLOs"] -- "bad" --> RB["Roll back"]
`}
/>

| Path                                              | Effort | Control | Fits                               |
| :------------------------------------------------ | :----- | :------ | :--------------------------------- |
| Frontend host (Vercel, Netlify, Cloudflare Pages) | Lowest | Low     | Next.js, static, SSG sites         |
| PaaS (Render, Railway, Fly.io, Heroku)            | Low    | Medium  | Most APIs and full stack apps      |
| VPS + Docker Compose + Caddy                      | Medium | High    | Learning, low cost, steady traffic |
| Containers on Cloud Run / ECS / Kubernetes        | Higher | High    | Growing teams and services         |
