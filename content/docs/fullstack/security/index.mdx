Security is mostly a set of defaults applied consistently: parameterised queries, escaped output, least privilege, secrets out of code, dependencies kept current. Auth-specific attacks are covered in [Attacks and Defenses](/fullstack/auth/attacks-and-defenses); this section covers the rest of the application.
