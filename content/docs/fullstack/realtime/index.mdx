HTTP was built for the client to ask and the server to answer. Chat, live dashboards, notifications, collaborative editing, and multiplayer features need the server to speak first. The transports differ in direction, overhead, and how hard they are to scale.

| Word          | Plain meaning                                             |
| :------------ | :-------------------------------------------------------- |
| **push**      | Server sends data without a new client request.           |
| **fan-out**   | Delivering one event to many connected clients.           |
| **presence**  | Who is online or viewing something now.                   |
| **backplane** | Shared channel (Redis, NATS) connecting servers' clients. |
| **CRDT**      | Data type that merges concurrent edits without conflicts. |
