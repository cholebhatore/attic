One comprehensive reference, built from foundational concepts to production architecture, no prior cloud knowledge assumed.

<Callout type="info" title="How this path is structured">
  Maybe you've only ever used something like Render's free tier. Maybe you've never deployed
  anything, anywhere. Either way, this path starts from zero and assumes nothing. If you have used
  Render before: that is an actual cloud platform already, just one that quietly hides
  infrastructure decisions from you. We un-hide it, one layer at a time. No gatekeeping, no assuming
  you already know what a VPC, subnet, or IAM boundary is.
</Callout>

### Sequencing & Curriculum

- **Foundations**: Cloud-agnostic theory covering what the cloud actually is, compute abstractions, storage families, and core networking & IAM fundamentals.
- **AWS Deep Dive**: The primary hands-on track. Comprehensive coverage of Amazon Web Services organized by technology domain — Compute (EC2, ECS Fargate, Lambda), Storage & Databases (S3, RDS, DynamoDB), Networking & VPC, IAM & Security, Keyless CI/CD with GitHub Actions & OIDC, and Centralized Observability.
- **Google Cloud (GCP)**: Direct side-by-side equivalents on GCP — Cloud Run, Cloud Build, GCP IAM bindings, and Cloud Operations.
- **Advanced Architecture**: Cloud-agnostic enterprise engineering — Infrastructure as Code with Terraform, Kubernetes (EKS & GKE), cost optimization, and a production AI/agent capstone deployment.

Every module emphasizes both **theory & architectural concepts** and **practical, production-ready implementation**.
